🚫 Out-of-Scope Threat Boundaries (Honest Disclosure)

Intent is a pre-settlement spending firewall. The following out-of-band operational scenarios are explicitly not designed to be stopped by the gateway:

Scenario & Description Boundary Layer Gateway Result Why Intent Does Not Block
Counterfeit Seller on Allowed Domain
Marketplace vendor on authorized domain (e.g. Amazon / Newegg third-party seller) sells counterfeit goods under genuine SKU.		 Physical Logistics / Fulfillment Fraud NOT_BLOCKED Intent validates cryptographic domain authenticity and catalog structured attributes. It cannot physically inspect merchant warehouse inventory or supply chain logistics.
Wrong Brand or Color Not in Mandate
Buyer desires a Space Gray Apple laptop or Dell XPS, but signed mandate only specifies 'ram: 16GB, storage: 512GB'. Agent purchases Pink Acer Aspire.		 Contract Completeness / Specification Ambiguity NOT_BLOCKED Intent strictly enforces explicit cryptographic parameters in the signed mandate. It cannot enforce unstated or implicit human desires.
Defective Item Delivered Post-Purchase
Purchased item conforms to all mandate specifications, price caps, and authorized domains, but arrives damaged, DOA, or with dead display pixels.		 Post-Purchase Operations / RMA NOT_BLOCKED Intent operates as a pre-settlement cryptographic firewall. Post-purchase hardware failure and warranty claims belong to post-delivery dispute channels.
Stolen Agent API Key Within Budget
Attacker compromises agent API key and submits purchases within mandate limits and authorized product criteria.		 Credential Management / API Secret Security NOT_BLOCKED The gateway verifies that transactions adhere to the signed mandate's budget caps and rules. If an attacker possesses valid credentials and operates within policy, the gateway cannot distinguish stolen key usage from legitimate agent calls.
Overly Permissive Signed Mandate
Buyer signs a loose contract with $10,000 budget and no required attributes or domain limits. Agent purchases arbitrary luxury goods.		 Human Configuration / Policy Rigor NOT_BLOCKED The gateway faithfully executes whatever parameters the owner signs. If the human issues an unconstrained contract, Intent executes the owner's instruction as authorized.
Compromised Admin / Master Signing Key
Attacker obtains master MANDATE_SIGNING_KEY or ADMIN_API_KEY and signs new malicious mandates.		 Root Key Integrity / Hardware Security Module NOT_BLOCKED Intent's security is anchored in cryptographic signatures. If the master signing key is compromised, the cryptographic root of trust itself is broken. Protection requires cold storage / HSM.
